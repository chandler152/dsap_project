# 山林接駁優化

## Proposal Report


### 動機與目標
台灣山林美景多集中在開車可達的熱門區，主因是大眾運輸不靈活，且密集的彎道與坡度對像我這樣易暈車的人來說是極大的心理障礙。目前的接駁系統缺乏對「路徑曲折度」與「遊客體質」的考量，導致許多秘境因交通「斷點」成為旅遊孤島。本計畫核心在於建立一套小巴路網優化模型，不僅量化路段的身體負擔，更著重於有效串聯多個潛在站點。透過重新規劃站點階級與接駁路徑，我們希望打破景點間的孤立狀態，建立一個具備包容性且高效的山林旅遊網絡，讓高質感的觀光不再受限於生理負荷。

### 預期功能
本計畫預期建立一套「動態路網診斷與優化模型」，將台灣山區地理環境轉化為具備多維權重的加權圖。系統核心功能在於量化路徑對遊客造成的身體負擔，透過整合距離、曲折度與坡度等關鍵參數，建立一套能反映真實旅遊痛點的評價體系。
在模擬分析層面，模型將引入遊客行為指標，模擬不同暈車耐受度的族群在面對大型巴士與小型接駁工具時的選擇邏輯。系統的主要任務是偵測並診斷「高吸引力但高交通阻力」的冷門節點，並進一步評定路線開發的經濟與社會價值。透過比較「投入接駁成本」與「提升之可達性與遊客流量」，模型能判斷特定路徑是否具備開發效益，進而針對路網斷點提供站點優化建議。最終，模型將輸出優化後的路線與站點規劃建議，證明透過彈性的低負擔運輸（如路徑靈活的小巴），能實質提升冷門景點的可達性，為台灣推廣兼具效益與包容性的旅遊方案。

### 使用技術
本計畫選用 C++ 作為核心開發語言。

關於路網資料來源，將分成兩階段進行。
第一階段（開發驗證）： 先利用自訂資料進行開發。我會針對台灣山路特性設計具備不同「曲折度分佈」與「站點距離」的測試資料，預計先自己定義簡單的資料確保實作邏輯順暢，接著可以撰寫程式碼製作路網產生器。這能讓我精確控制變數，調整權重公式與平均舒適度算法的正確性，避免初期被真實數據的雜訊干擾。

第二階段（實務數據）： 現實中已有成熟的資料來源可以支持本模型，例如OpenStreetMap (OSM) 的路網資料有詳細的道路節點。我接下來會研究哪一個資料來源最適合此次專題，並思考如何轉化為我需要的資料型態。


### prototype預計可驗證內容

第四週：原型整合與文字介面開發
完成 Console UI 開發，整合路網運算邏輯，讓使用者能透過交互輸入獲得小巴路徑規劃與預估負擔分數，正式提交 Prototype 驗證核心可行性。

### 後期計劃

第六週：秘境開發價值評估系統
建立成本效益評判邏輯，結合景點吸引力與潛在流量增量，開發自動化標註功能，判斷特定冷門路段是否具備投入小巴接駁的經濟效益。

第七週：系統壓力測試與穩定度優化
利用較大規模虛擬資料進行路網模擬與壓力測試，檢查記憶體管理（Memory Leak）狀況，確保演算法執行效率並完成最終開發報告。

## Prototype Report

### 目前進度
路網與感官權重建模：
完成了 MountainMap 類別，利用鄰接串列儲存站點與路段。在 Road 結構中實作了動態權重計算，將物理數據（距離、平均轉彎角度、轉彎頻率）整合為單一的體感負荷指標。以北宜公路「九彎十八拐」作為 Curvature = 1.0 的標準化基準，使數據具備現實參考意義。

變體 Dijkstra 演算法實作細部流程：
為了尋找「體感代價最低」而非單純「距離最短」的路徑，實作流程如下：
1.初始化：建立 min_weight 陣列紀錄起點到各站的最輕負荷（初始為無限大），起點設為 0；並準備 parent 陣列用於路徑追蹤。
2.優先隊列排序：使用 priority_queue 並自定義比較運算子（>），確保每次提取的都是當前累積權重最小的節點。
3.邊緣鬆弛與感官介入：從隊列取出站點 u 。遍歷 u 到鄰居 v 的所有路段。調用 edge.getWeight(sensitivity)。此步驟會計算 dist + (dist*curvature)^(1.5)* sensitivity，將生理累積性直接轉化為圖論中的「邊長」。若「u 的權重 + 該段體感權重 < v 的既有權重」，則更新 v 的權重並將 parent[v] 設為 u。
4.路徑重建：當搜尋抵達終點後，利用 parent 陣列從終點反向回溯至起點，再進行 reverse 排序，產出最終導航序列。

群體敏感度決策模型：考量山區小巴的多人搭乘情境，實作了群體敏感度運算：採用 0.7*max(S) + 0.3*avg(S) 的加權方式。此邏輯能確保在群體導航中，系統會自動優先避開會導致最易暈車者嘔吐的高風險路段。

### 遇到的困難
1.累積性邏輯的量化誤差：初期發現純線性的加權無法有效區分「一長段連續彎路」與「多段分散小彎」的痛苦差異。解決方案：透過對數值進行 1.5 次方處理，模擬前庭系統在持續受刺激下負擔呈指數上升的真實生理反饋。
2.真實地理數據的落差：手動在地圖上計算彎道效率過低。解決方案：確立了透過 OpenStreetMap (OSM) 節點座標進行向量運算的技術流程，將複雜的道路形狀轉化為可計算的角度與頻率參數。
3.山區運輸的現實限制：考慮到山區接駁車班次較少，無法採取「中途下車休息以回復感官」的策略。因此，模型必須在一次性的連續行程中，找到能撐到終點的最佳路徑，這增加了演算法在篩選路段時的難度。

### 下一步計畫
1.整合 GIS 自動化處理 Pipeline
開發 DataConverter 工具，實作 Haversine 公式計算經緯度間的精確距離。利用向量內積運算（Dot Product）自動解析 OSM 原始路徑中的 Node 序列，自動產出各路段的平均轉向角度與頻率，達成從「地圖數據」到「權重參數」的自動化轉換。
2.優化「時間 vs 舒適度」權衡模組
目前的演算法可能為了極致舒適而選擇繞路過遠。計畫引入「時間容忍門檻」，當繞路時間超過最短路徑的 150% 時，引入懲罰因子，在「不暈車」與「準時抵達」之間尋找帕累托最優解。
3.多路徑對比與視覺化評級
在 Console UI 基礎上，整合「路徑對比功能」，同時顯示「最短路徑」與「最舒適路徑」的負擔分數對照。將抽象的權重分數轉化為具體的「乘客不適等級（Level 1-5）」，提供直覺的決策參考。

## Final Report

### 專案說明
一、 專案動機

傳統大眾運輸導航多以「最短時間」或「最短距離」為單一優化目標，卻忽略了山區觀光接駁中，乘客對連續彎道的生理不適（暈車風險）以及中途景點的觀光動機。本專案以南投竹山文化園區至溪頭自然教育園區之真實公車路網為情境，開發一套兼顧乘車舒適度與地方觀光效益的大眾運輸智慧調度決策系統。

二、 核心技術與功能實作

### 使用方式
1. 系統簡介
本程式為 Console 文字介面 的山林小巴路線決策原型。啟動時會:
(1)從 route1.txt、route2.txt、route3.txt 讀取真實 GPS 軌跡，自動計算各路線的距離、彎道角度、轉彎頻率；
(2)建立含 5 個站點的路網圖（鄰接串列）；
(3)請使用者輸入群體敏感度與起訖站 ID；
(4)輸出導航決策報告（建議路線、路徑、體感負擔分數等）。
(5)使用者不需輸入 GPS 或彎道參數，僅需輸入敏感度與站點編號。

### 與課程的關聯總結
這套系統作為資管的資料結構專題，最亮眼的地方就在於它完美示範了「如何用資訊技術解決真實世界的管理與營運痛點」。
一、技術層面的連結：經典資料結構與演算法的非線性延伸
本專案的核心完全扣合課程相關的經典圖形理論與最短路徑演算法，但我們更進一步將理論進行了實務上的優化：
圖形結構與邊緣萃取： 我們將現實中的山區道路（151縣道、投55鄉道）抽象化為資料結構中的加權圖。節點代表接駁站點，邊則不只是死的距離，而是透過海維辛公式與向量夾角公式，從 GPS 軌跡大數據中動態萃取出的「物理距離、轉彎角度與頻率」特徵。
Dijkstra 演算法與優先佇列： 系統採用 std::priority_queue 實作最小優先佇列優化，將搜尋時間複雜度有效降低。
邊緣鬆弛的創新定義： 課堂上學到的「鬆弛」通常是單純的數值加總與覆蓋。在本專案中，我們大膽重寫了鬆弛的評估邏輯——在 edgeEffectiveWeight 運算中，將「觀光吸引力」設計為負權重（減免紅利）。當演算法進行 Relaxation 掃描時，如果中繼點的觀光價值夠高，便能成功觸發 if 條件並更新 min_weight 陣列，這在資料結構的實作上是非常漂亮且具備前瞻性的延伸應用。

二、應用層面的連結：大眾運輸智慧調度與地方永續營運
這部分的應用篇幅，能將專案從「單純的程式作業」拔高到「智慧交通與城鄉永續」的戰略高度：
大眾運輸營運商的「動態班次調度決策」：
1.對客運或公車營運商來說，傳統固定路線無法滿足多變的觀光市場。本系統提供了一個數據驅動的決策工具。當客運公司在後台輸入當日預約乘客的群體體質數據（如長者團體敏感度高，一般年輕人團體敏感度低），系統能秒級自動產出最佳的客運路線調度指引。高敏感度走直達保證服務品質；低敏感度走繞路創造附加價值，達成「精準排班」的管理目標。
2.推廣台灣山區觀光與地方創生（以南投溪頭、竹山為例）：
山區偏鄉觀光（如孟宗竹林古戰場）常因為交通不便、缺乏專屬運具接駁而面臨邊緣化。本專案將公車路線與景點吸引力綁定，透過演算法主動引導耐受度高的公車班次繞行至潛力景點。這不僅能為偏鄉景點注入穩定的大眾運輸客流、活絡地方經濟，更能實質推動地方創生。
3.落實 ESG 綠色交通與大眾運輸推廣：
台灣山區每到假日往往因自駕遊客過多導致交通癱瘓。本系統透過同理乘客暈車痛點的「人性化路線規劃」，能有效提升遊客搭乘「台灣好行」等山區觀光公車的意願。藉由提高綠色運具（大眾運輸）的市占率，能減少私人載具的碳排放與山區交通擁堵，完美呼應現代智慧城市對 ESG 永續發展與綠色運輸 的核心營運要求。
